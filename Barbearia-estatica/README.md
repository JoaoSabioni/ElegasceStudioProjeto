# Elegance Studio - site estatico temporario

Esta pasta contem uma copia estatica do site publico da barbearia, sem a area de marcacoes.

## Como usar

Abrir `index.html` diretamente no browser. As paginas funcionam sem API, sem base de dados e sem Node.js.

## Paginas

- `index.html` - inicio, destaque, precario resumido, trabalhos recentes e contactos.
- `servicos.html` - precario completo.
- `galeria.html` - espaco, equipa, contactos, Instagram/WhatsApp e lightbox simples.
- `politica-privacidade.html` - politica adaptada a esta versao estatica.

## Nota

Os links de contacto usam telefone, WhatsApp e Instagram. Nao existe formulario de marcacao nem chamadas ao backend.
