# Elegance Studio - site estatico

Esta pasta contem o site publico estatico da barbearia.

## Como usar

Abrir `index.html` diretamente no browser ou servir esta pasta como site estatico.

## Paginas

- `index.html` - inicio, destaque, precario resumido, trabalhos recentes e contactos.
- `servicos.html` - precario completo.
- `galeria.html` - espaco, equipa, contactos telefonicos e lightbox simples.
- `politica-privacidade.html` - politica adaptada a esta versao estatica.

## Publicacao

Publicar o conteudo desta pasta (`Barbearia-estatica/`) no alojamento estatico. A pagina inicial e `index.html`.

## Nota

Os links de contacto usam telefone e o link de direcoes abre o Google Maps.
