# Elegance Studio - site estatico

Site estatico da barbearia Elegance Studio, em Pinhal Novo.

O projeto agora e apenas HTML, CSS, JavaScript e imagens.

## Estrutura

```txt
Barbearia-estatica/
  index.html
  servicos.html
  galeria.html
  politica-privacidade.html
  styles.css
  script.js
  assets/
```

## Como usar

Abrir `Barbearia-estatica/index.html` diretamente no browser.

Tambem pode ser publicado em qualquer alojamento estatico.

## Contactos

As paginas usam apenas links telefonicos para contacto direto com a equipa.
